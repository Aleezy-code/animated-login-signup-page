## 🌟 About the Project

The **Animated Login & Sign Up Page** is a front-end web development project designed to make the authentication experience more attractive and interactive.

Instead of switching between separate pages, users can move between the login and registration interfaces using a smooth sliding animation.

This project demonstrates how HTML, CSS and vanilla JavaScript can work together to create a modern user interface without a heavy framework.

## ✨ Features

- 🔄 **Smooth Animations** — Animated transitions between Sign In and Sign Up.
- 🎨 **Modern UI Design** — Clean layouts, gradient colors and polished form elements.
- 🔐 **Dual Authentication Interface** — Login and registration form layouts.
- 🌐 **Social Login UI** — Visual placeholders for social sign-in options.
- 🖱️ **Interactive Controls** — Buttons to switch between authentication panels.
- ⚡ **Lightweight Codebase** — Built using standard web technologies.
- 🧩 **Easy to Customize** — Modify colors, typography, spacing and animations.
- 🚀 **Quick Setup** — No complex installation or build process required.

## 🚀 Getting Started

Run the project locally in just a few steps.

### 1. Clone the repository

```bash
git clone https://github.com/Aleezy-code/animated-login-signup-page.git
```

### 2. Open the project folder

```bash
cd animated-login-signup-page
```

### 3. Launch the website

Open `index.html` in your preferred web browser.

**That's it!** No npm installation or build command is required for this basic front-end project.

For development, you can also open the folder in Visual Studio Code and use the Live Server extension.

## ⚙️ How It Works

1. HTML defines the login form, registration form and surrounding layout.
2. CSS controls the appearance, positioning and animation effects.
3. JavaScript handles the interaction that switches between the two form states.
4. CSS transitions animate the interface when the relevant state changes.

## 🔒 Important Security Note

This project currently demonstrates a **front-end authentication interface**. It should not be treated as a production-ready authentication system.

Actual login, registration, account storage, password recovery and social authentication require suitable backend services or a trusted authentication provider. Never store plain-text passwords or secret API keys in front-end code.
